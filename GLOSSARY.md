# Glossary

Two words only: the two that this repo's talk and tickets mix up. Every other word is the skills' own, defined in the words blocks named in [`docs/agents/domain.md`](docs/agents/domain.md); reuse it, and never redefine it here.

**The skills**: the Claude Code plugin `matt-with-paseo` (with its `matt-with-paseo-streams` skill), the core that decides and keeps working without the plugin.
_Avoid_: "the plugin".

**The plugin**: only this Paseo plugin, `matt-with-paseo-plugin`, optional, doing the mechanics the skills' prose cannot do reliably.
_Avoid_: "the skills" for it. Never call the skills "the plugin".
